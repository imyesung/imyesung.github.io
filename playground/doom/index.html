How this works

DOOM shipped in 1993 as a DOS program. DOS (Disk Operating System) was the text-based OS that preceded Windows—you typed commands into a prompt to launch executables. A modern browser has no idea what to do with a DOS binary. The black text scrolling on startup? That’s a real DOS environment booting.

The trick is js-dos, an open-source project that compiles DOSBox—a full x86 CPU and DOS environment emulator—into WebAssembly (Wasm), a low-level binary format that runs inside the browser at near-native speed. Here’s what happens when you hit Start:

A CDN (Content Delivery Network) is a geographically distributed cluster of servers that serves static files from whichever node is closest to the user. The ~2 MB DOOM bundle is hosted on js-dos.com’s CDN. Nothing is installed on your machine—everything lives in the browser tab’s memory and disappears when you close it.

Beyond DOS

This isn’t limited to DOOM or even DOS. The general principle: if an emulator exists for a platform, it can be compiled to WebAssembly and run in a browser. DOSBox handles DOS programs. v86 emulates a full x86 PC and can boot Windows 95, 98, or even Linux. Console emulators for the NES, SNES, and Game Boy Advance have all been ported to Wasm. The constraint is performance—emulation has overhead—but for anything from the pre-2000s era, a 2026 machine has cycles to spare.
