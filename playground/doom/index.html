How this works

DOOM shipped in 1993 as a DOS program. DOS (Disk Operating System) was the text-based OS that preceded Windows—you typed commands into a prompt to launch executables. A modern browser has no idea what to do with a DOS binary.

The trick is js-dos, an open-source project that compiles DOSBox—itself a full x86 CPU and DOS environment emulator—into WebAssembly. WebAssembly (Wasm) is a low-level binary format that runs inside the browser at near-native speed. So what you get is a virtual 1993 PC, booting virtual DOS, running the original DOOM.EXE, all inside a browser tab in 2026.

The game files live on a CDN (Content Delivery Network)—a geographically distributed cluster of servers designed to serve static assets from whichever node is closest to the user. When you open this page, the browser pulls a ~2 MB bundle from js-dos.com’s CDN, js-dos mounts it into a virtual filesystem, and boots DOOM.EXE from there. Nothing is installed locally.
