# Fonts

Latin Modern Roman 2.004 by GUST e-foundry (B. Jackowski and J. M. Nowacki),
derived from Donald Knuth's Computer Modern.

| File | Face | Used as |
| --- | --- | --- |
| `lmroman10-regular.woff2` | LM Roman 10 Regular | 400 normal |
| `lmroman10-italic.woff2` | LM Roman 10 Italic | 400 italic |
| `lmromandemi10-regular.woff2` | LM Roman Demi 10 Regular | 600 normal |
| `lmroman10-bold.woff2` | LM Roman 10 Bold | 700 normal |

The files are the original OpenType fonts from TeX Live repackaged as WOFF2.
Outlines, metrics, and features are untouched. Only four faces of the family
are shipped here. This selection is not supported by the original authors.
