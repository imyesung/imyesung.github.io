How a 1993 DOS Binary Runs in a 2026 Browser

Systems · WebAssembly · 2025

DOOM shipped in 1993 as a DOS binary, and a modern browser has no idea what to do with one. The trick that lets it run anyway — a full x86 CPU emulator compiled to WebAssembly — is more interesting than the game itself.

The trick

DOS (Disk Operating System) was the text-based OS that preceded Windows; you typed commands into a prompt to launch executables. DOOM was one of those executables: a single binary that talked directly to the x86 CPU, VGA card, and Sound Blaster, with no kernel or window manager standing in between.

The ~2 MB DOOM bundle is hosted on js-dos.com’s CDN. Nothing is installed on the machine — everything lives in the browser tab’s memory and disappears when the tab closes.

Beyond DOS

This pattern isn’t limited to DOOM or even DOS. If an emulator exists for a platform, it can be compiled to WebAssembly and run in a browser. v86 emulates a full x86 PC and can boot Windows 95, 98, or Linux. Console emulators for the NES, SNES, and Game Boy Advance have all been ported to Wasm. The constraint is performance — emulation has overhead — but for anything from the pre-2000s era, a 2026 machine has cycles to spare.
